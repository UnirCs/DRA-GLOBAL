## ejercicios/

Cada carpeta tiene un `-start.html` para empezar y la solución con el mismo nombre sin `-start`. Intentadlo antes de mirar la solución.

| Carpeta | Qué se hace | Epígrafe |
|---|---|---|
| `ej02/` | Un botón con cuatro animaciones distintas: bounce, wobble, rubberBand y swing | 2.5 |
| `ej03/` | Una tarjeta que aparece al pulsar un botón: `@keyframes`, `animation-play-state` y `animation-fill-mode` | 2.5 |
| `ej04/` | La misma tarjeta, con una custom property que controla la velocidad de toda la animación | 2.6 |
| `ej05/` | La misma tarjeta, respetando la preferencia de movimiento reducido | 2.7 |

Para probar `ej05` tenéis que activar la opción de reducir el movimiento en vuestro sistema operativo y recargar la página.
